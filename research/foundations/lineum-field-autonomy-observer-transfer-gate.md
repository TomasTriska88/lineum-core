## 2. Why P2 is not run yet

The root programme classifies P2 as a source-off transported multi-defect or vortex-gas remnant, not a localized particle or persistent identity. The current minimum-flux observer is non-identifying because smooth transported disorder can pass it.

Directly applying the point observer to P2 would therefore combine two unresolved steps:

1. whether the causal observer survives conversion from labeled points to unlabeled fields;
2. whether P2 contains any field-compatible object and intervention to which that observer applies.

This report isolates only the first step. P2 remains prohibited until the field-readout transfer passes and a separate field-native causal intervention is frozen.

## 7. Field rendering

Every point state is converted into a scalar density field:

```text
rho(x) = sum_i exp(-|x - x_i|^2 / (2 sigma^2))
```

Before rendering, the point center of mass is subtracted. The rendered field is normalized to unit discrete mass.

Frozen rendering parameters:

```text
primary grid = 64 x 64
refinement grid = 128 x 128
square domain = [-2.4, 2.4) x [-2.4, 2.4)
Gaussian sigma = 0.12
boundary treatment = no wrap inside the centered render window
field dtype = float64
```

The domain is large enough for all centered hidden states in the declared fixture. Any mass touching the outermost four grid cells above `1e-8` of peak density invalidates that trajectory rather than being silently clipped.

Two renderers are required:

```text
renderer A = explicit sum over sixteen Gaussian components;
renderer B = vectorized broadcast over points and grid.
```

Their normalized fields must agree to maximum absolute error below `1e-13` for seed `700`, `dt=0.005`, all six causal cases, at the primary grid.

## 8. Field-only signatures

No signature receives point coordinates, point labels, edges, forces, case names, or the original reference geometry.

### 8.1 Radial-angular moment magnitude signature

For centered grid coordinates `(r, theta)`, define eight Gaussian radial windows with centers evenly spaced from `0.10` to `1.65` and width `0.18`. For angular modes `m = 0..8`:

```text
M[b,m] = sum_grid rho(r,theta) w_b(r) exp(-i m theta)
S_moment = abs(M) / (abs(M[0,0]) + 1e-15)
```

Flatten `S_moment` into a real vector. Magnitudes remove global rotation and reflection sign. Centering removes translation.

### 8.2 Autocorrelation quantile signature

Compute the discrete autocorrelation:

```text
C = real(ifft2(abs(fft2(rho))^2))
```

Normalize `C` by its maximum, sort all values, and sample 128 equally spaced quantiles. The resulting vector is translation invariant and approximately rotation invariant on a refined grid.

Autocorrelation is not a complete identity invariant. Homometric fields can share it. It is retained only as an independent ensemble member, never as a sole identity proof.

### 8.3 Differential restoration

Each challenged state `C` has a matched no-challenge twin `T` with identical seed, formation history, timestep, law, and observation times.

For signature `S`:

```text
d0 = RMS(S(C_initial) - S(T_initial))
df = RMS(S(C_final) - S(T_final))
R = 1 - df / d0
```

A trajectory is invalid if `d0 < 1e-8`, because the field observer did not resolve the injury.

The two primary restoration scores are:

```text
R_moment
R_autocorr
R_field = min(R_moment, R_autocorr)
```

Using the minimum prevents one weak or degenerate signature from rescuing the other.
