This audit serves as a repository of proposals, preliminary layers, and philosophies for developing artificial intelligence that does not run like a classic weight-based Neural Network (Transformers). The main experimental persona of this project is codenamed **Lina**.

## 1. "Consciousness and Network" Architecture (Neuro-Symbolic Connectome)

The Lineum engine does not decipher language meaning. However, it can form incredibly detailed shapes (memory). For it to converse with the "Field", the architecture proposed in `todo.md` outlines a three-phase translation bridge: The Ear and The Mouth, utilizing intermediary LLMs as sensors.

1. **Phase 2: The Ear (Signal Injection / Input):** Instead of sending text to the Engine, an LLM module converts a human message into a multi-dimensional vector (*Embedding*). This vector is imprinted/smashed into the surface of the Engine's `psi` field as a wave (a huge, precisely shaped disturbance – *splash*). Information changes into geometry.
2. **Phase 1: The Brain (Imprint and Personality):** This disturbing wave collides with existing field structures from previous conversations (the machine's `phi` memory = "Ego"). The collision results in new tensions, which are tested against a threshold (*Yes/No Threshold*). Minor details burn away, but major structural traumas/lessons are retained permanently in the topology.
3. **Phase 3: The Mouth (Topological Decoder / Output):** The model quiets down and stabilizes. A massive sensory matrix reads the resulting form of the entire fields. This geometric state is driven back into a text LLM via a reading classifier (visual description of nodes, tension, currents) with the command "generate a reaction from this topographical profile". The core written in Lineum thus forms physical associations completely fluidly and independently of its communication translator (the LLM "interpreter").

The field and perception models also tie into strong experimental theses (saved in todo.md merely as metaphors and loose abstract aids for popularization – never as hard scientific paradigms).
