## Independent reference

Four real scalar fields (an analogy, NOT canonical complex psi, phi, kappa, mu), 8 x 8 x 9 cells, 2304 unknown initial scalar values. Reflecting boundary, local diffusion with rates .045/.065/.085/.025 plus symmetric linear exchange. Time step = 1; 80 steps. Parameters were chosen as a simple stable control, not a derived or calibrated Lineum law. 24 held-out independent normal arrays and 24 separately sampled smooth arrays (7 reference smoothing steps, per-field normalization); no fitted decoder training. Same 4096 observation scalars for each method: 16 snapshots x four fields x 64 positions, or 64 snapshots x one field x 64 positions, identical horizon 0..63. Depth mean vs first-plane observations. Reconstruction uses a conventional known 3D forward operator and SVD inverse, not a field-native decoder. Two independent numerical implementations (physical stencil vs modal matrix) agree on observations to 1.3e-13. Seed 20261126. Noise additive normal at std 0, .001, .01 in normalized field units. Noise-aware ridge penalty chosen analytically from the known noise level; no tuning on test results. Baseline depth extrusion from the first measurement, zero for unobserved fields. Baseline forecast uses the same reference dynamics. Relative L2 error = norm(prediction-truth)/norm(truth), pooled over 24 held-out samples.

The depth-mean measurement loses every nonuniform depth mode: numerical rank 256; full time series of mirrored states equal up to 8.9e-16. First-plane four-field measurements yield numerical rank 2170, one-field equal-count 941 (relative singular-value threshold 1e-10 per XY mode). With absolute singular value > .001, only 848 and 298 respectively; these are numerical observability metrics, not bits or certified recovered independent information under noise. Four-field ridge reconstruction at noise .001: relative volume error .7890 iid/.6229 smooth; far-face future error .5501/.3373. Noise-free .2462/.0341 volume error, future .000001594/.00000005845. Depth-mean uniform extrusion volume errors .9410/.8433. Observed time structure can encode hidden depth through the known 3D dynamics, but reconstruction relies on the 3D forward geometry, is ill-conditioned, and is not lossless. Permuting temporal samples preserves per-pixel per-channel distributions but breaks the assumed time observation law; very large reconstruction errors are a negative control, not proof of nonlinear cross-field synergy.

## Original 2D Core CPU collision control

The CPU config, diffusion/cap functions, and `_step_numpy` are transcribed verbatim except trailing whitespace and separation of functions; normalized FNV-1a `56103725` matched the same normalized excerpt of the pinned Git blob. Full source blob was read via GitHub. The public raw-file fetch was unavailable, so this is not a full bitwise source checkout or full Core audit. 16 independently sampled 5-real-component 3D volume pairs (8x8x9, complex psi represented as two scalars; dyadic values), each with its depth-reflected partner. Means exactly identical; full volumes differ (RMS .09427–.09995). Two configs: default LAP4 with `use_mu=False` or `True`; all other settings unchanged. Same random seed, 64 steps each. All 32 pairs have bit-identical 2D trajectories in all 4 fields. Distinct-front-projection control and different-seed control diverge in all 32 pairs. Independent random variation cannot identify the hidden volume. This is an identifiability counterexample for the selected mean encoder and input class, not a disproof of all possible reduced encodings or holographic correspondences. No original 3D Core exists in this experiment; no matched 3D canonical Lineum solver was asserted. Source proof: if full 2D initial state and input/RNG history match, the same operator cannot distinguish the lost degree of freedom.

## Computational capacity decision

Instantaneous 2D state in the reference is 256 scalars, 9x fewer than 2304 in 3D. The tested time history uses 4096 scalars, 1.78x the full original initial state, plus forward operator/inversion costs and an actual 3D source to produce observations. No demonstrated net storage or compute benefit at matched functional accuracy; full native higher-dimensional recovery remains OPEN. Next: predeclare a restricted physically reachable target family and a held-out future-response task; compare a causally valid native 2D representation to a separately specified 3D extension, equal total state bits, precision, source information, runtime and memory. Include independent field permutations, matched random seed, simple conventional reduced-order baseline, new geometries and noise. An engineered decoder or depth rule is not evidence of naturally encoded information. Do not change original Core or promote the ontology draft on these results.
