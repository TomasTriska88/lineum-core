# Historical projection-origin evidence (2026-11-26)

This supporting audit motivated the holographic-representation research. It concerns a renderer's depth assignment, not native 3-D field evolution. The unchanged historical audit ZIP includes both projector implementations, the original audit program, its results, log and comparison image. `used_frames.npz` preserves byte-exact uint8 arrays of every source and reference opacity sample used in that audit: 32 frames (60 through 91 inclusive), 96 by 96 pixels, from the flame alpha channel. `input_provenance.json` records original archive and full source-member digests, the exact selection and each array digest. The two asset archives contain an identical source member.

The full asset delivery ZIPs and unused channels/frames are deliberately not replicated here; their preservation in an asset repository is not established by this import. The historical audit.py expects the original full asset directory layout. This evidence import does not claim that those complete archives are in Git or that a new simulation was run.

Interpretation: changing the imposed width of a rendering depth distribution can increase side-view contrast even without retaining hidden geometry; the contrast is not evidence for native holography. No production physics or asset generator changes.
